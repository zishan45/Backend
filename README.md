## Running the Projects

Clone the repository:

```bash
git clone <your-repository-url>
```

Move into the required project folder:

```bash
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
node index.js
```

For projects using a development script:

```bash
npm run dev
```
